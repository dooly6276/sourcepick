# Security

Sourcepick has no server and stores settings only in your browser. The extension asks for `storage` and for access to search result pages on Google, DuckDuckGo and Brave Search, nothing else.

If you find a security problem (for example a way for a shared source link to run code or to send data anywhere), please report it privately through [Security advisories](https://github.com/dooly6276/sourcepick/security/advisories/new) instead of opening a public issue. You will get a reply within a few days.
