# Privacy policy

Sourcepick (web app and browser extension for Chrome, Edge and Firefox)

## English

Sourcepick collects no personal data. It has no account, no server of its own, no analytics and no advertising.

- **What is stored.** Your settings (selected sources, your own sources, search engine, time filter) are stored on your device: in the browser's extension storage for the extension, in the browser's local storage for the web app. They never leave your device.
- **What is sent.** When you search, the query and the sites you selected are sent to the search engine you chose (Google, Bing, DuckDuckGo or Brave Search) as an ordinary search request. Sourcepick does not see or keep it. The engine's own privacy policy applies to that request.
- **What the extension reads.** On the results pages of those four engines, the extension reads the search query and the address parameters to show which sources are applied. It reads nothing else on the page and nothing on other sites.
- **Permissions.** `storage` saves your settings. Access to search results pages shows the source buttons there. The `sp` address-bar keyword searches with your sources.
- **Share links.** A source shared as a link contains only its name and list of sites, encoded in the address. Nothing is uploaded; the link is read in the browser of whoever opens it.
- **Web app hosting.** The web app is a static site on GitHub Pages at sourcepick.toolnjoy.com. The host can keep ordinary access logs of page requests, as any web host does; Sourcepick adds no cookies or tracking.
- **Children, sale of data, third parties.** No data is collected, so none is sold, shared or used for any other purpose.

Questions: open an issue at https://github.com/dooly6276/sourcepick/issues

## 한국어

Sourcepick은 개인정보를 수집하지 않습니다. 회원가입, 자체 서버, 분석 도구, 광고가 없습니다.

- **저장하는 정보**: 선택한 출처, 내 출처, 검색엔진, 검색 기간 같은 설정은 사용 중인 기기에 저장됩니다. 확장 프로그램은 브라우저의 확장 프로그램 저장소, 웹 앱은 브라우저의 로컬 저장소를 사용하며 기기 밖으로 전송되지 않습니다.
- **전송되는 정보**: 검색하면 검색어와 선택한 사이트가 선택한 검색엔진(구글, Bing, DuckDuckGo, Brave)으로 일반 검색 요청처럼 전송됩니다. Sourcepick은 이 정보를 보거나 보관하지 않으며, 해당 요청에는 검색엔진의 개인정보 처리방침이 적용됩니다.
- **확장 프로그램이 읽는 정보**: 위 네 검색엔진의 검색 결과 화면에서 적용된 출처를 표시하기 위해 검색어와 주소 매개변수를 읽습니다. 그 밖의 화면 내용과 다른 사이트의 정보는 읽지 않습니다.
- **권한**: `storage`는 설정 저장, 검색 결과 화면 접근은 출처 버튼 표시, 주소창 키워드 `sp`는 선택한 출처로 검색하는 데 사용합니다.
- **공유 링크**: 링크로 공유한 출처에는 이름과 사이트 목록만 주소에 포함됩니다. 업로드되는 정보는 없으며, 링크를 연 사람의 브라우저에서 읽습니다.
- **웹 앱 호스팅**: 웹 앱은 sourcepick.toolnjoy.com의 GitHub Pages 정적 사이트입니다. 호스팅 서비스는 일반적인 접속 기록을 보관할 수 있으며, Sourcepick은 쿠키나 추적 도구를 추가하지 않습니다.
- **제3자 제공**: 수집하는 정보가 없으므로 판매, 공유, 다른 목적의 사용도 없습니다.

## 日本語

Sourcepick は個人情報を収集しません。アカウント、独自のサーバー、分析ツール、広告はありません。

- **保存する情報**: 選んだ検索先、自分の検索先、検索エンジン、検索期間などの設定は、お使いの端末に保存されます。拡張機能ではブラウザの拡張機能ストレージ、ウェブアプリではブラウザのローカルストレージを使い、端末の外には送信されません。
- **送信される情報**: 検索すると、検索語と選んだサイトが、選んだ検索エンジン (Google、Bing、DuckDuckGo、Brave) に通常の検索リクエストとして送信されます。Sourcepick はこれを見ることも保存することもありません。このリクエストには各検索エンジンのプライバシーポリシーが適用されます。
- **拡張機能が読む情報**: 上記 4 つの検索エンジンの検索結果ページで、適用中の検索先を表示するために検索語とアドレスのパラメータを読みます。ページのそれ以外の内容や他のサイトの情報は読みません。
- **権限**: `storage` は設定の保存、検索結果ページへのアクセスは検索先ボタンの表示、アドレスバーのキーワード `sp` は選んだ検索先での検索に使います。
- **共有リンク**: リンクで共有した検索先には、名前とサイトの一覧だけがアドレスに含まれます。アップロードされる情報はなく、リンクを開いた人のブラウザ内で読み取られます。
- **ウェブアプリのホスティング**: ウェブアプリは sourcepick.toolnjoy.com の GitHub Pages 上の静的サイトです。ホスティングサービスは一般的なアクセスログを保持することがありますが、Sourcepick は Cookie やトラッキングを追加しません。
- **第三者への提供**: 収集する情報がないため、販売、共有、他の目的での利用もありません。
