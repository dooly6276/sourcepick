# Code of Conduct

Sourcepick follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks are not accepted in issues, pull requests, discussions or anywhere else in the project.

To report a problem privately, use [GitHub's private vulnerability and abuse reporting](https://github.com/dooly6276/sourcepick/security/advisories/new) or contact the maintainer through their GitHub profile. Reports are handled confidentially.
